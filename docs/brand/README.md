# RPA logo

One glyph, three letters: the R's stem is also the A's left leg, the R's leg is
the A's right leg (both at 20°), and the bowl's base is the A's crossbar.

| File | Use |
|---|---|
| `rpa-black.svg` | One-colour master (#0A0A0B) on light backgrounds |
| `rpa-white.svg` | Reversed, on dark backgrounds |
| `rpa-mint.svg` | Brand colour (#0B7A4B, passes 3:1 on white) |
| `../../public/favicon.svg` | Favicon: mint #3DDC97 glyph on a #0A0A0B tile |

- Geometry: 256 grid, cap height 184, weight 34, bowl radius 66/32. Filled outlines only.
- Minimum size: 16px (favicon). In the header it sits in a 30px tile at 22px.
- Clear space: one stem width (34/256 of the mark) on every side.
- Don't: add outlines or shadows, stretch, re-slant, or set "RPA" in a font next to it.
