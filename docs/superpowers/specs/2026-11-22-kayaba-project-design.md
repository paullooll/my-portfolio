# KayaBa? project entry + cover + demo video: short design

**Intent:** add KayaBa? (`Personal/kayaba`, repo `paullooll/kayaba-mobile`, public) to Projects the same way SOLID, ChorDefine and AmbatuHelp were done. It is a personal project still in development.

**Goals:** real entry in `src/content.ts` (problem, solo role, features, "in development" result, stack); a new `Personal` filter tag; a designed cover in the KayaBa? palette; a ~30 s voiced 1920×1080 demo at `public/projects/kayaba-demo.webm`.
**Non-goals:** a live link (none exists); changing the featured three.
**Anti-goals:** claiming it is released or finished; inventing users or numbers.

**Approaches:** (1) reuse the cover + AmbatuHelp video tooling with the existing screenshots in `kayaba/docs/revamp/`: chosen. (2) fresh captures from a Flutter web build: rejected, needs Supabase keys and the UI is still moving. (3) entry + cover only: rejected, breaks the pattern.

**Decided:** not featured (shown under "show all" and the Personal filter). Palette Dagat Blue `#0038A8` / Araw Gold `#FCD116` / cream `#FAF8F3`, Cubao display font. Voice `af_heart`.
**Left to the builder:** scene count, exact narration and cover composition.
